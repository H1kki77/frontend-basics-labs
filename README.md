## Запуск локально

Лаби 1–6 і 8 — статичні сторінки. Можна відкрити `index.html` у браузері або запустити простий сервер з кореня репозиторію:

```bash
python3 -m http.server 8000
```

і перейти на http://localhost:8000/.

Лаба 7 (React + Vite) потребує Node.js 20.19+ (вимога Vite):

```bash
cd lab-7
npm install
npm run dev      # режим розробки
npm run build    # збірка в lab-7/dist (вона ж публікується на GitHub Pages)
```
